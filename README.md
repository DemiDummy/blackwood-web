# Blackwood Manor

A first-person survival horror demo in the vein of the original Resident Evil: a decaying manor at night, a storm,
a handgun with too few rounds, and the things shuffling through the east wing.
**Play it at https://demidummy.github.io/blackwood-web/** (Chrome, Edge or Firefox on a desktop; headphones help).

WASD move, mouse look, Shift run, right mouse aim, left mouse fire, E interact, R reload, F flashlight,
Tab inventory, Esc pause.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
